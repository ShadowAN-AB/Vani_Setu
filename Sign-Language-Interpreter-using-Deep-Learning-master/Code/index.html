About Vani-Setu

Vani-Setu (“voice-bridge”) is a camera-based sign language translator for classroom and accessibility demos. It tracks one hand with MediaPipe, maps poses to words or letters, speaks the result, and can translate English into Hindi and other languages.

College iteration

  • Working Indian Sign Language (ISL) input mode — simplified single-hand classroom signs.
  • A landmark dataset recorder and Random Forest trainer with a confusion matrix for the report.
  • Offline Hindi fallback when Google Translate is unavailable.
  • SMTP secrets moved to .env. OTP prints in the terminal when email is not set.

Honest limits

  • One hand, static poses only (no motion letters J/Z, no two-handed ISL).
  • Rule-based poses until you record samples and run train_classifier.py.
  • ISL here is a teaching approximation, not a certified ISL lexicon.
